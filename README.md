# 喀兰贸易技术研发部 · 最佳策略求解器 & 全自动冲分助手

面向《明日方舟》SideStory「雪山降临1101」小游戏 **「喀兰贸易技术研发部」** 的实时识图、精确全局最优策略求解与全自动挂机凹分工具，支持 **Windows PC 端直连** 与 **MuMu 模拟器 ADB** 双模式，并内置 **OBS Studio 自动录制高光（仅留破纪录视频，废片自动删除）**。

---

## 核心特性

### 1. 毫秒级精确全局策略求解器 (`solver.py`)
- **全机制精确建模**：前进、采集（`点数 × 基础产出 × 倍率`）、严格递增 `+1` 触发 `COMBO+`（不耗前进卡且全种类资源 `+2`）、3 条计划资源全共享、完成即时刷新、主动提前结束回合留位、过圈永久加产（第 5 关 `+1` / 第 10 关 `+2`）、第 7/8/9 关手牌动态扩容（4→8 张）、以及第 6/10 关宝箱 `3^m` 精确概率期望。
- **Pareto 非支配剪枝 + 奇偶回合前瞻**：将 `×4` 大单溢出与 `×1` 小单溢出独立剪枝防误剪；偶数回合末针对持续存在的 `×2` 区域前瞻卡位；5 牌关单步搜索 **≤ 5ms**，8 牌关 **< 300ms**。
- **动态重同步**：每当计划完成或开启宝箱后自动暂停连打并重新识图重算，保证剩余手牌基于最新任务给出最优解。

### 2. 双端自适应视觉识别 (`vision.py`)
- **PC 端窗口直连 + MuMu 模拟器 ADB** 一键切换，支持双尺度模板匹配（兼容模拟器 `1.0x` 与 PC 端 `0.90x` UI 缩放）。
- **Held-Karp 精确 TSP 环形构图**：自动将地图上 10 个资源点还原为严格顺时针环路，完整覆盖全 10 关（前 5 关：齿轮/水晶/木头；后 5 关：水晶/火苗/工字钢）。
- **实时识别**：站位与基础产出、`×2` 优质收获区、红斜杠封锁区、宝箱、3 条计划进度、手牌点数与 `COMBO+` 标记、以及结算页大号红字精准读分。

### 3. 全自动通关 / 反复冲分 / 1~10 关全自动连刷 (`app.py`)
- **单局通关 / 反复冲分（可设盘数 & 目标停机分）/ 1~10 关连刷队列** 一站式管理。
- **等效分中盘剪枝重开**：到达检查回合时按 `等效分 = 已结算重建值 + 3 条未完成任务进度折算分` 判定，既可砍掉低分烂局省下 2~3 倍时间，又不会误杀刚交大单或差临门一脚的高分潜力局。
- **闭环防漏牌 & 防误弃安全闸**：每出一张牌均实时校验手牌数量变化，未生效自动重试绝不漏牌；认为手牌已空时若弹出确认框自动点「取消」返回继续出牌。
- **系统级全局急停热键**：运行中随时按 **`F10`** 或 **`End`** 键立即中止并释放鼠标。

### 4. OBS Studio 高光自动留存 (`obs_ctrl.py`)
- 通过 OBS 内置 WebSocket v5 自动控制每局启停录制。
- 仅当打破当前关卡最高纪录（或达成目标分）时自动重命名珍藏（如 `S01_地基重建_24分_20261123_175614.mp4`），未破纪录或中盘剪枝的废片自动清理，多关连刷时每关独立保留一条最高分录像。

## 快速开始

### 方式一：下载 Windows 免安装版（推荐）
1. 前往本仓库右侧 **Releases** 下载 `Arknights-Karlan-RD-Solver-v1.0.0-win64.zip` 并解压到任意英文/常规路径。
2. **PC 端玩家**：双击 `start_admin_pc.bat`（自动请求管理员权限以向管理员运行的《明日方舟》PC 端发送点击）。
3. **MuMu 模拟器 / 手动沙盒玩家**：直接双击 `KarlanRDSolver.exe`。
4. 浏览器会自动打开 `http://127.0.0.1:5050`。

### 方式二：从源码运行
需要 Python 3.10+：

```bash
git clone https://github.com/mwty-0415/arknights-karlan-rd-solver.git
cd arknights-karlan-rd-solver
pip install -r requirements.txt
```

- **PC 端模式**（需要管理员权限）：双击 `start_admin.bat`
- **模拟器 ADB 模式**：双击 `start.bat` 或运行 `python app.py`

### 自行重新打包 Windows 免安装版
```bash
pip install pyinstaller
python build_release.py
```
打包产物将生成在 `release/Arknights-Karlan-RD-Solver-v1.0.0-win64.zip`。
